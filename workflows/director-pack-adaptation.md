# Director pack: adopted practices and local adaptations

Source: the creator's supplied seven-skill Director transcript, 2026-10-27. This records
an adaptation of that text; it does not verify the Marketplace's exact files,
installed skill versions or the Director bot's ability to access this project.
Maintain one canonical harness rather than seven competing production drivers.

| Supplied skill | Useful practice | Application here |
| --- | --- | --- |
| video-director | Brief -> project -> plan -> frames -> takes -> edit -> delivery | Existing six stages; user authorization and project constraints govern. No blanket approval gate for a long/public film, and no automatic music/voice/captions |
| video-formats | Coverage and pacing should suit the format | Examples are starting points, not compulsory runtime/shot quotas. Use the creator's selected ratio/audio and one consistent delivery aspect |
| video-planning | Named cast/set, look lock, shot list and planned joins | Record before generation, with camera/axis/eyeline, action beat and sound. Existing complete packet remains authoritative |
| video-look | Reusable identity references and a compact visual lock | Inspected cast/equipment/set masters and useful views; compare every endpoint. Correct affected references/frames when wardrobe or gear changes |
| video-frames | Approve stills; use the actual accepted end for a same-camera continuation | Both FIRST and LAST remain required for every planned shot in the creator's workflow. Changed angle gets matching staged endpoints; Loop is an actual UI role, not guaranteed merely by repeating one file |
| video-takes | Logged KEEP/REDO/FAIL with a bounded attempt budget | Separate visual/audio acceptance, diagnose a causal change, preserve raw takes and respect complete-first-pass review. Query actual supported resolutions; do not impose480p drafts or promise1080p |
| video-project-folder | One resumable film packet and untouched sources | Channel-owned text/media locations and relative tracked paths; reuse existing equivalent documents instead of duplicating a runtime-specific folder tree |

The pack's supplied-face restriction is not adopted as a universal generation
rule. Use the actual user brief, available references and applicable policy.
Explicitly supplied real-person likenesses are identity references, not evidence
that an unseen file or promised asset exists.

New operational guidance lives in [project preparation](project-preparation.md)
and [asset ledger](asset-ledger.md). Native editing mechanics remain in
[Stitch timeline](stitch-timeline.md); editorial decisions are in
[editing grammar](editing-grammar.md). A changed shot updates its dependent
endpoints/joins and a new movie version; unrelated accepted shots stay reusable.

Delivery requires the actual accessible movie file, ordered keepers and honest
review limits. A screenshot, registered ID or Agent description alone is not a
delivered MP4. Do not infer listening approval from a successful audio decode.
